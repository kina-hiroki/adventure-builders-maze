# 3D Maze

縦7m・横7m、壁の高さ1.5mの迷路を表示する、ブラウザ用の3D図です。通路配置は仮案です。

## 開き方

`index.html` をダウンロードし、ブラウザで開いてください。インストールやビルドは不要です。

GitHub上のファイル一覧ではHTMLのソースが表示されます。迷路図を見るには、ダウンロードした `index.html` をブラウザで開きます。

## 操作

設定は迷路図の下に、次の順で縦に配置しています。

1. 正解ルートの表示・非表示
2. 視点の切り替え：斜め・真上・真横の自由回転・正面・右側・背面・左側
3. 回転角度の変更
4. 拡大率の変更：100〜300%
5. 壁の半透明表示
6. 壁面への1m間隔の縦の点線表示

100%表示では図をドラッグすると回転し、拡大中はドラッグで表示位置を移動できます。「全体表示」で拡大率と表示位置を戻します。

正解ルートは入口から出口までの通路に沿って表示します。壁に隠れる部分は点線で補います。

## ファイル

- `index.html`：通常のブラウザで開ける単体HTML
- `source/maze-3d.html`：編集元となる会話用のHTML断片
- `README.md`：この説明書

`source/maze-3d.html` を編集した場合は、配布用の `index.html` にも変更を反映してください。

## 確認内容

- 外寸7m × 7m、壁の高さ1.5m
- 入口から出口までの経路と、壁を横切らないこと
- 視点・回転・拡大・移動・全体表示の操作

- 通常幅とスマートフォン幅での設定の縦並び
